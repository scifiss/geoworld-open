# Security Policy

## Supported version

Only the latest revision on the default branch is supported during the project’s alpha stage.

## Reporting

Please do not open a public issue for a suspected vulnerability or exposed secret. Use GitHub’s private vulnerability reporting for `scifiss/geoworld-open` when available, or contact the repository owner through the security contact listed on the GitHub profile.

Do not include credentials, private data, exploit payloads, or production GeoWorld details in a public report.

## Scope

GeoWorld Open is a local educational package, not the production GeoWorld service. Reports about the hosted production platform should be submitted privately through its designated channel rather than this public issue tracker.

See [security design notes](docs/security.md) for repository safeguards.
