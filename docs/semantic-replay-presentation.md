# Ordinary-model Scientific Figures and bounded context evidence

The normal GeoWorld Assistant remains the only composer. Ordinary GeoSpec results
now open one Scientific Figures workspace with facies and porosity selected.
Selection order determines plot order. Calculated fields are optional; aggregate
figures are downloads rather than additional copies of each field. New Vp/Vs
exports have an explicitly shared absolute m/s scale and separate-scale variants.
Older plots retain their recorded scales; aggregate-only results remain visible once.

The backend supplies a recorded parameter table (Parameter / Value / Source),
methods, numerical ranges/finite checks and artifact provenance. Raw specs/downloads
are secondary; parameter origins absent from older records are not reconstructed.
Scientific data and all numerical downloads remain unchanged.

`StudioBuildContext` optionally retains its original bounded typed `NewBuild` action
and source prompt. The protected backend decides whether these can be replayed and
revalidates them. The client does not perform scientific or semantic admission.
Follow-up patches preserve this origin independently of the current edited GeoSpec.
Existing sessions without the new optional origin fields remain compatible.

Focused public Studio/context/connection/presentation tests: 50 passed. The matching
private evidence contains genuine authenticated Studio requests, selected-field
screenshots, parameter facts, numerical identity and provenance checks. No merge,
deployment, scientific algorithm or independent benchmark generator change.
