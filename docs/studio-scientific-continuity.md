# Scientific workspace and conversation recovery

The scientific workspace stays on the left and the single Assistant on the
right (approximately 68% / 32%). At narrow widths the workspace precedes chat.
The chronological history scrolls independently; older turns are retained.
An answer about saved scientific evidence appears in chat once, while the
active job's numerical views remain in the workspace. The latest answer is
not the authoritative scientific referent.

Overview shows saved porosity, CO₂ saturation, P-wave velocity change and
far-angle PP response change on their common along-line distance / baseline
TWT coordinates. Models & Figures supports selecting up to four available
fields, explicit Move earlier / Move later ordering, and display scaling.
These operations do not submit numerical jobs. The optional selected PNG is
generated by the protected backend from verified saved arrays, with one to
four scalar panels and 150 or 200 dpi. Unsupported section sizes are rejected;
this is not an arbitrary publication/export service.

Scientific Evidence / Provenance presents recorded assumptions, methods in
execution order, parameters with units, numerical controls, state lineage,
algorithm versions and verification. Complete Details keeps readable
assumptions/limitations first. Raw records remain available under Advanced.

## HTTP contracts

All routes require the existing bearer authentication and account ownership.
Public presentation code imports no private package.

| Route | Purpose |
| --- | --- |
| `PUT /studio/conversations/{conversation_id}` | Save bounded chronological transcript, revision, active completed scientific job reference, selected field order |
| `GET /studio/conversations` | List at most five recent unexpired conversations for this account; no transcript bodies |
| `GET /studio/conversations/{conversation_id}` | Restore transcript; scientific context only after protected source/artifact verification |
| `POST /jobs/{job_id}/scientific-figure` | Optional bounded PNG of selected saved scalar fields; creates no numerical job |

The transcript contract allows at most 1,000 messages, 32,000 characters per
message and 2,000,000 characters of serialized transcript. It accepts no secret,
array or provider-state fields. Scientific authority remains the referenced
job and verified artifacts, never the text. Saves use optimistic revisions;
stale sessions cannot overwrite accepted turns. Validation or save failure
preserves the current browser history and shows an actionable warning.

## Recovery boundaries

After refresh/disconnect, sign in and choose **Restore recent scientific work**
→ **Restore conversation and results**. No job identifier is required.
The server window is three hours from the last saved change, exceeding two
hours. The seven-day authentication default is unchanged; conversation expiry
and JWT expiry are separate. Selected field order is restored; display zoom,
drafts, pending build preparations and arbitrary specialized workflow state
remain browser-local. This is working-session recovery, not durable project
memory.

Recovery requires the database and original job files. Missing or unverifiable
artifacts restore the transcript with an explicit warning, without claiming
scientific recovery. Database persistence cannot recover files lost from
ephemeral storage or deleted by artifact retention. No durable storage was
introduced. Existing users and scientific source admission are unchanged.
